# 儿童活动排期及海报制作

用于 Codex 的每周儿童活动工作流技能，覆盖排期核对、双语课程流程、营销审查、海报样张、PNG制作、修订验收和归档清理。

## 安装

下载本仓库，将仓库文件夹重命名为 `weekly-course-posters`，复制到个人 Codex 技能目录 `~/.codex/skills/`。

## 使用

在 Codex 中输入以下请求，并提供目标周课表、对应教案及项目目录。

> 请使用 $weekly-course-posters，准备下一周儿童活动排期及海报。

## 工作流程

1. 读取项目交接和最新实际资料，核对课程事实及双语表达。
2. 根据对应教案整理完整活动流程，检查营销表达。
3. 制作课程总览和单节课海报两类实际样张，交由用户确认。
4. 制作中文总览、英文总览、全篇中英对照长版及双语分龄方图。
5. 检查文字、时间、年龄、老师、地点、计费、流程、Logo和画面质量。
6. 交付PNG文件夹，更新交接，按授权范围清理过程图。

## 文件

- `SKILL.md` 包含执行规则。
- `references/error-checks.md` 包含返工错误检查清单。
- `agents/openai.yaml` 定义技能显示名称及默认调用提示。

## 使用准备

在实际项目中提供 `HANDOFF.md`、当周课表、对应教案、品牌Logo及风格参考。图像生成和表格编辑需要当前环境具备相应工具。

## 定时执行

本仓库包含技能定义。每周五14:00（Asia/Shanghai）的执行计划应在使用者自己的 Codex 中单独配置，安装技能后按需设置。
