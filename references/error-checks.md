# 从返工记录提取的必查项

这些例子用于识别错误类型。每周具体值从当周资料核对。

| 曾出现的问题 | 验收动作 |
| --- | --- |
| 旧周信息进入本周 | 逐场对照最新课表和确认记录，检查取消场次是否恢复 |
| 其他课程的老师和医生串入当前主题 | 为每个主题独立核对老师与合作机构，检查所有名字的归属 |
| 时间在课表、总览、长版不同步 | 比较同一日期和年龄的所有关联文件，核实当前成品后再修改 |
| 新增课只补长版 | 核销中英文总览、长版、分龄方图和课表的受影响项 |
| 未满2岁等边界丢失 | 双语完整表达边界，特殊适龄单独标清 |
| 地点缩写或校徽校名替代幼儿园场地 | 用确认的完整地点，合作Logo名称与实际场地分别核对 |
| 教案玩法被想象补全 | 核对每项来源，未知材料、路线、实验或环节集中确认 |
| 流程漏项或编号跳列 | 按正常阅读顺序逐行核对，标明分龄专属项目 |
| 中英文译名和事实不对应 | 统一主题、类型、场地与流程译名，逐场核对数字和人名 |
| 穹窿山、曜影医疗、南瓜感官盆等形近字漏检 | 放大看部件和笔画，穹窿山的窿有穴字头，盆下为皿；同时检查导出PNG |
| 校字引起排版重做 | 以原图为构图约束，核查标题大小、布局和其他正文有无漂移 |
| 反复编辑积累色块斑驳和失真 | 使用干净原始参考重新生成，检查文字区、色块、边缘和角色细节 |
| 清理脏斑导致手撕纸感和笔触消失 | 分别检查纸张撕边、层叠阴影、胶带和插画笔触，文字纸面保持整洁 |
| 标题太大、副标题重复、局部拥挤又留空 | 手机尺寸检查层级与空间，全文搜索意义重复的信息 |
| Logo缺角色、变形、文字错误或双Logo位置错误 | 核对原三角色、品牌中英文、完整比例及合作Logo并排 |
| 单课主题画面全部套同一模板 | 逐主题检查构图和场景是否呼应实际课程 |
| 使用第三方角色图案 | 检查原创造型及素材来源，保留确认名称与实际活动内容 |
| 方图混入排课信息 | 对照主题、真实年龄、完整Logo三类字段 |
| 最终目录混入失败稿、旧稿或待修订稿 | 逐文件检查版本，只有通过稿进入最终取用区 |
| PNG/JPG旧规则被带到新交付 | 默认仅PNG及文件夹，数量以本周实际设计数计算 |
| 将部分完成报告为全部完成 | 逐项统计实际文件，将失败或待确认项明确列出 |
| 清理后误报释放空间 | 记录实际删除方式和字节，移入废纸篓仍占磁盘空间 |

确认检查结果时记录实际检查的文件和范围。未变化文件可通过内容指纹证明沿用已有验收，避免声称重新逐字检查了所有图片。生成服务失败时记录真实错误和未完成项，后续依据新授权及当前能力判断处理方式。
